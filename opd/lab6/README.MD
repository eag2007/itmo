## Что делает программа
Производит обмен по прерыванию. Переменная X в цикле увеличивается на 2. С ВУ-2 происходит ввод значения X, на ВУ-3 происходит вывод значения F(X) = 5X - 3

| Режим | Действие |
|-------|----------|
| **Основная** | `X = X + 2` (цикл) |
| **ВУ-2 (F2)** | читает данные → записывает в `X` |
| **ВУ-3 (F3)** | выводит `5*X - 3` |
| **ОДЗ** | `-25 ≤ X ≤ 26` |
| **Выход за ОДЗ** | `X = -25` |

## Векторы

| Вектор | Обработчик |
|--------|------------|
| V2 | ВУ-2 |
| V3 | ВУ-3 |
| остальные | `IRET` (пустышка) |

## MR настройка

| ВУ | Адрес | Значение |
|----|-------|----------|
| ВУ-2 | 5 | `0xA` |
| ВУ-3 | 7 | `0xB` |
