### Основная программа

**Назначение**  
Асинхронный вывод строки на устройство ВУ-1 (кодировка КОИ-8).  
Строка завершается символом `NUL` (0x00), который выводится как обычный символ, после чего программа останавливается.

**Структура строки в памяти**  
Слова по 2 символа:  
`АДР1: СИМВ1 СИМВ2`  
`АДР2: СИМВ3 СИМВ4`  
…  
`СТОП_СИМВ (0x00)`

**Размещение**  
- Программа: начало с `0x2AF`  
- Строка: начало с `0x584`  
- Строка в памяти: `0xD1E2, 0xE4CE, 0xCDD1, 0x3600` (в КОИ-8 — **"Привет"**)

**Алгоритм**  
1. Проверка готовности ВУ-3 (бит 0x40)  
2. Переключение режима `MODE`:  
   - `MODE=0` → вывод старшего байта, `MODE=1` → вывод младшего  
3. Вывод символа на ВУ-2  
4. Проверка на `NUL` (0x00)  
5. Если `NUL` — останов, иначе повтор

**Ключевые переменные**  
- `MODE` (0x2AF) — режим вывода  
- `INDEX` (0x2B1) — указатель на текущий символ

### Дополнительное задание: Загрузчик команд

**Задача**  
Программа вводит с ВУ-3 16-кодные команды (сначала старшая часть, потом младшая).  
При вводе команды `HLT` (0x0100) управление передаётся **первой введённой команде**, которая выполняется.

**Пример ввода**  
`40 22` → команда `0x4022`

**Особенности реализации**  
- Первая команда сохраняется как точка входа  
- Остальные команды последовательно записываются в память  
- `HLT` не сохраняется, а служит триггером запуска

**Переменные загрузчика**  
- `START_ADDR` — адрес первой команды  
- `ADDR_PTR` — указатель для записи команд
